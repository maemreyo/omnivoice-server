## Validation Command Matrix

### 1. Library: transformers Backend (Default)

**Environment**: Linux/macOS/Windows, CPU/CUDA
**Backend**: transformers (default)
**Mode**: Clone with auto-transcription (`ref_text=None`)

```bash
# Command
python3 -c "
from omnivoice import OmniVoice
import soundfile as sf
model = OmniVoice.from_pretrained('k2-fsa/OmniVoice', device_map='cpu')
audio = model.generate(
    text='Hello world',
    ref_audio='test_audio.wav',
    ref_text=None  # Triggers auto-transcription
)
sf.write('out.wav', audio[0], 24000)
print('SUCCESS: transformers backend clone with auto-transcription')
"

# Expected Result
- Exit code: 0
- Output file: out.wav exists and is valid audio
- Log contains: "ASR backend selection: transformers"
- Log contains: "Loading transformers ASR backend"

# Pass/Fail Criteria
PASS: Exit 0, out.wav created, no exceptions
FAIL: Non-zero exit, missing output, or exception raised
```

## Rollback Validation Commands

### 12. Rollback: Environment Variable Method (All Entry Points)

**Scenario**: Switch from faster-whisper back to transformers

```bash
# Step 1: Set to faster-whisper
export OMNIVOICE_ASR_BACKEND=faster-whisper
omnivoice-infer --model k2-fsa/OmniVoice \
  --text "Test" --ref_audio test.wav --output out1.wav

# Step 2: Rollback to transformers
export OMNIVOICE_ASR_BACKEND=transformers
omnivoice-infer --model k2-fsa/OmniVoice \
  --text "Test" --ref_audio test.wav --output out2.wav

# Expected Result
- Both commands succeed
- out1.wav log shows: "faster-whisper"
- out2.wav log shows: "transformers"
- No code changes required

# Pass/Fail Criteria
PASS: Both succeed, logs confirm backend switch
FAIL: Either command fails or backend doesn't switch
```

---

### 13. Rollback: CLI Flag Override (OmniVoice CLI Tools Only)

```bash
# Step 2: Override with CLI flag to transformers
omnivoice-infer --model k2-fsa/OmniVoice \
  --text "Test" --ref_audio test.wav --output out.wav \
  --asr-backend transformers

# Expected Result
- Command succeeds
- Log shows: "ASR backend set to: transformers"
- Log shows: "ASR backend selection: transformers"
- CLI flag overrides env var

# Pass/Fail Criteria
PASS: Command succeeds, transformers backend used despite env var
FAIL: Command fails or faster-whisper used

# Note: This rollback method does NOT apply to omnivoice-server
# (server has no --asr-backend CLI flag)
```
