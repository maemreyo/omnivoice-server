QA Scenario 1: Server can force each backend

Implementation:
---------------
File: omnivoice_server/config.py
Added field:
  asr_backend: Literal["transformers", "faster-whisper"] | None = Field(
      default=None,
      description="ASR backend for auto-transcription. "
      "None = use OMNIVOICE_ASR_BACKEND env var or default (transformers). "
      "Supported: 'transformers' (default), 'faster-whisper'."
  )

File: omnivoice_server/app.py
Added startup logic:
  if cfg.asr_backend:
      import os
      os.environ["OMNIVOICE_ASR_BACKEND"] = cfg.asr_backend
      logger.info(f"  asr_backend={cfg.asr_backend} (set via config)")

Backend Selection Mechanism:
-----------------------------
Precedence: CLI/config > env > default

1. Via config field:
   OMNIVOICE_ASR_BACKEND=transformers omnivoice-server
   → Server uses transformers backend

2. Via env var:
   OMNIVOICE_ASR_BACKEND=faster-whisper omnivoice-server
   → Server uses faster-whisper backend

3. Default (no config, no env var):
   omnivoice-server
   → Server uses default (transformers)
