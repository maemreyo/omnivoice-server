Backend Selection Mechanism:
-----------------------------
Precedence: CLI flag > env > default

All CLI tools use the same mechanism:

1. Via CLI flag:
   omnivoice-demo --model k2-fsa/OmniVoice --asr-backend transformers
   → Demo uses transformers backend

2. Via env var:
   OMNIVOICE_ASR_BACKEND=faster-whisper omnivoice-demo --model k2-fsa/OmniVoice
   → Demo uses faster-whisper backend

3. Default (no flag, no env var):
   omnivoice-demo --model k2-fsa/OmniVoice
   → Demo uses default (transformers)
