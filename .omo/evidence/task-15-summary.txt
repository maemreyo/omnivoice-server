**Ground Truth Verified**:
- `omnivoice_server/cli.py`: No `--asr-backend` argument defined

- `OmniVoice/omnivoice/cli/demo.py`: `--asr-backend` flag exists
- `OmniVoice/omnivoice/cli/infer_batch.py`: `--asr-backend` flag exists

**Fix Applied**:
- Corrected all command matrix entries to distinguish server vs CLI tools
- Updated rollback command 13 to clarify CLI flag override only works for OmniVoice CLI tools
- Added explicit notes throughout document clarifying server has no CLI flag
- Updated precedence descriptions to be scoped per entry point
