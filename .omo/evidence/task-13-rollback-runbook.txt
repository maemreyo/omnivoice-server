Rollback Methods Documented:
-----------------------------

Method 1: Environment Variable (Recommended)
- Use case: Quick rollback without code changes
- Command: export OMNIVOICE_ASR_BACKEND=transformers
- Rollback time: < 5 minutes (restart required)
- Verification: Check logs for "backend: transformers"

Method 2: CLI Flag (Immediate)
- Use case: Single invocation rollback
- Command: --asr-backend transformers
- Rollback time: Immediate (no restart)
- Verification: Check logs for "ASR backend set to: transformers"

Method 3: Server Config Field (Persistent)
- Use case: Permanent rollback for server
- Command: export OMNIVOICE_ASR_BACKEND=transformers
- Rollback time: < 5 minutes (restart required)
- Verification: Check logs for "asr_backend=transformers (set via config)"
